## How to apply

When generating a page, ask:

1. **Which persona is this page primarily for?** (one primary, optionally one secondary)
2. **Are there hooks from that persona's list that fit naturally?** Don't force; if the natural copy lands, ship it.
3. **Are there objections worth addressing inline?** Add one early in the page if it shortens the path to conversion.

**Rule:** a page doesn't try to address all four personas at once. Pick one primary + maybe one secondary.
